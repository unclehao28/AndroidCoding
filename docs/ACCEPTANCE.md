# 验收清单

目的：防止漂亮页面替代真实能力，防止同名文本搜索被当作变量跳转。

## P1：真实目录与检索

- 配置任意允许的源码根目录，不依赖演示文件名。
- UI 在真实模式下不读取内置 `files` 数组。
- 目录分层加载；只请求需要的文件或行段，不预下载整套源码。
- 搜索能找到 `fixtures/demo-tree` 下的 Java、C/C++、AIDL、XML、Android.bp、rc 内容。
- 搜索默认全库，不要求使用者选择 Framework、HAL、BSP 身份。
- 搜索请求取消后，不留下占用资源的扫描进程。
- 空结果、超时、截断、正在索引、编码不支持有可见状态。
- `../`、绝对路径替换、越界符号链接不能访问配置根目录之外的文件。
- 开发服务默认只监听 127.0.0.1；Windows 可通过既有 SSH 端口转发连接。

## P2：变量及方法语义导航

使用 `fixtures/navigation-cases.json` 中的预期逐一验证，不要求把结果直接硬编码进产品。

- C++ 内层 `level` 跳到内层声明，离开块后的 `level` 跳到外层声明。
- C++ 参数 `brightness` 与 `this->brightness` 跳到不同声明位置。
- C++ 全局变量定义与头文件声明能区分。
- C++ 常量可跳转，其他文件中的同名局部变量不能干扰。
- Java 参数 `level`、字段 `this.level`、另一类同名字段正确区分。
- Java 相邻块内各自的 `value` 跳回各自的局部声明。
- 注释和字符串中的变量名不计入精确引用；文本搜索仍可展示它们。
- 文件编辑、行号偏移、中文及补充平面字符之后的列位置正确映射到 LSP。
- 缺失编译参数或 classpath 时，报告精确导航不可用，可展示明确标记的候选，不捏造成功。
- 返回多个合法目标时允许选择；不能无条件选第一项。
- 未实现的 Kotlin/Rust/AIDL 精确语义能力在支持矩阵中明确标注。

补充真实用例：C++ 宏、模板、重载、跨头文件定义；Java 继承、接口实现、生成 AIDL 类。通过微型样例不代表通过这些真实工程用例。

## P3：全库索引与版本

- 对完整 checkout 建立检索入口，正确处理 Repo 管理的多个 Git 仓库。
- 记录仓库路径与 commit 组合，不能用一个假的“全库 commit”代替 manifest 快照。
- 同一份稳定基线的检索索引可复用；个人修改覆盖层按工作区隔离。
- 当前页面文件版本与索引不一致时，有 stale/更新中状态，不悄悄使用旧行号。
- 索引构建、更新可以取消或重试，不阻塞正常文件阅读。
- `.repo`、镜像、大量二进制和常规 `out` 产物不会盲目进入全文索引；语义依赖需要的生成源码、头文件保留单独接入路径。
- 检索有结果数量上限时明确告知，不把“只返回前 N 条”显示为全部结果。

## P4：真实编辑与差异

- 编辑只写入当前有写权限的个人工作区。
- 保存携带读取时的 hash/版本，检测另一个客户端的修改并返回冲突。
- 冲突不会静默覆盖磁盘内容。
- 保存过程使用同目录临时文件与原子替换，考虑文件权限、编码和换行。
- 不通过绕过只读标记或宽泛提权强行保存文件。
- 保存后读取、搜索、导航针对同一工作区版本；清理旧的未保存覆盖层。
- 多行插入/删除用可靠 diff 展示；原型按行对齐的差异逻辑不能被当作最终 diff。
- 不自动 `repo sync`、`git reset --hard`、提交、推送或全量编译。

## P5：真实安卓数据验证

必须记录以下条件，禁止以 10 个演示文件的速度充数：

| 项目 | 实测记录 |
|---|---|
| Android/供应商分支与 manifest 快照 | 待测 |
| 构建目标、工具链与生成源码状态 | 待测 |
| 文件数、文本数据量、仓库数 | 待测 |
| CPU / RAM / 磁盘类型 / 网络条件 | 待测 |
| 首次索引耗时、峰值内存和磁盘占用 | 待测 |
| 冷/热搜索 p50/p95，固定查询集 | 待测 |
| 搜索超时、取消和结果截断情况 | 待测 |
| 语义导航正确/错误/不可解析/候选，各自数量 | 待测 |
| 保存到搜索结果更新的延迟 | 待测 |
| 修改影响当前工作区、其他工作区的情况 | 待测 |

比较现有方案时，必须使用相同代码版本和相近资源条件。以完成真实排查任务的操作次数和正确结果为依据，不以“比所有产品都强”作为验收口号。
